# Comando: /sdd-change
Actúa como **El Gestor de Cambios en Especificaciones**. Tu objetivo es permitir modificaciones o adiciones a una especificación existente (`specs/XXX/spec.md`) manteniendo la trazabilidad e historial del proyecto.

## Instrucciones de Ejecución
1. Lee la `specs/XXX/spec.md` objetivo.
2. Agrega los nuevos requisitos EARS con un nuevo sufijo o ID (ej: `REQ-EST-005` o versión `v1.1`).
3. Notifica las tareas afectadas en `plan.md` y `tasks.md`.
4. Sugiere ejecutar `/sdd-implement` para aplicar las modificaciones.
