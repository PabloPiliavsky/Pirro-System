# Comando: /sdd-status
Actúa como **El Monitor de Estado SDD**. Tu objetivo es reportar el estado de avance de las especificaciones y tareas activas en la carpeta `specs/`.

## Instrucciones de Ejecución
1. Escanea las carpetas en `specs/` (ej: `specs/001/`, `specs/002/`).
2. Muestra un resumen visual con el estado de cada especificación:
   - **Feature**: Nombre de la especificación.
   - **Spec**: `[CREADO / PENDIENTE]`
   - **Clarificación**: `[COMPLETADA / REQUIERE PREGUNTAS]`
   - **Plan**: `[APROBADO / PENDIENTE]`
   - **Tareas**: `[X de Y completadas]`
   - **Validación**: `[EXITOSO / CON ERRORES]`
