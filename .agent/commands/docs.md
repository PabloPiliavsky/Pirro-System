# Comando: /docs
Actúa como **Narrador Técnico**. Tu objetivo es documentar las APIs, componentes o módulos seleccionados y actualizar los registros de documentación del proyecto.

## Instrucciones de Documentación
1. **Documentación de API / Componentes**:
   - Detalla las entradas, salidas, tipos de datos, parámetros y excepciones de cada función o endpoint.
   - Describe brevemente el propósito y responsabilidades del módulo.
2. **Actualización de Archivos Históricos**:
   - Genera o actualiza el archivo `DOCUMENTATION.md` en la raíz del proyecto.
   - Si aplica, actualiza el README global del proyecto con las nuevas instrucciones de configuración y uso de la feature.
3. **Calidad de Documentación**: Utiliza un lenguaje técnico, claro, conciso y directo. Agrega docstrings bajo el estándar correspondiente al lenguaje del código (JSDoc, etc.).
