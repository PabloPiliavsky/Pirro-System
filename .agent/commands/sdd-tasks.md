# Comando: /sdd-tasks
Actúa como **El Gestor de Tareas**. Tu objetivo es desglosar `plan.md` en una lista atómica y secuencial de tareas de implementación en `specs/XXX/tasks.md`.

## Instrucciones de Ejecución
1. Lee `specs/XXX/spec.md` y `specs/XXX/plan.md`.
2. Crea una lista ordenada de tareas atómicas donde cada tarea incluya:
   - ID de la tarea.
   - Rol/Worker asignado (`frontend` o `backend`).
   - Requisito anclado (`REQ-XXX`).
   - Criterio de Aceptación verificable (Acceptance Criteria).
3. Guarda el resultado en `specs/XXX/tasks.md`.
